## Migrating to another GitHub account

When moving to a production account:

1. Transfer repo or push copy to new account
2. Update `site_url` and `repo_url` in `mkdocs.yml`
3. Re-enable GitHub Pages → GitHub Actions
4. Update QR codes and packaging links

See [Adding Documentation](adding-documentation.md) for URL find-replace checklist.
