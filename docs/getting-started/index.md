## Before you begin

HackCard ships **without pre-loaded firmware**. You will:

1. Install the Arduino IDE and ESP32 board support
2. Install required libraries
3. Download the HackCard firmware / library from GitHub
4. Flash an example sketch via USB-C

!!! info "No SD card required"
    The first flash and all basic tutorials work without a microSD card.

---

## Success criteria

After completing this section you should see:

- Arduino IDE connects to HackCard on a COM port
- Upload completes without errors
- Serial Monitor at **115200 baud** shows boot messages
- RGB ring or status LED responds (depending on example)
