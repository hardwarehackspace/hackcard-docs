# Tutorials

Step-by-step guides with **code**, **hardware photos**, and **expected Serial output**. Each tutorial maps to one Arduino example sketch.

---

## How to use tutorials

1. Complete [Getting Started](../getting-started/index.md)
2. Pick a tutorial below
3. Open the matching example in Arduino IDE
4. Upload and follow the steps
5. Compare your Serial output to the expected output section
